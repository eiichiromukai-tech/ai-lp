物件写真を置くフォルダです。

ファイル名のつけかた
  <物件番号>-<番号>.jpg              例: CMP-1025-01.jpg
  <物件番号>-<番号>_キャプション.jpg  例: CMP-1025-02_内装.jpg

  ・番号 01 の写真が一覧カードとメイン画像になります
  ・1物件あたり10枚まで（11枚目以降は掲載されません）
  ・使える拡張子: jpg / jpeg / png / webp / avif / gif
  ・長辺1600px程度・1.5MB以下におさめてください

置いたあとに次を実行すると反映されます。
  node tools/csv-to-properties.js

写真を消したいときは、このフォルダからファイルを削除して
同じコマンドを実行してください。
