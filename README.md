# RE/MAX COMPASS（株式会社ロメッツ）LP

商業不動産・店舗仲介を専門とする RE/MAX COMPASS（株式会社ロメッツ）のランディングページ。

**注意**: 本サイトには実在する会社の会社概要情報（所在地・電話番号・宅建免許番号等）を掲載しています。公開前に必ず内容の正確性をご確認ください。

## デザインシステム

`REMAX_LP_Design_Prompt.md` の指示に基づき、**CBRE Japanのレイアウト言語 × RE/MAXブランドアイデンティティ（2026年版）のカラー・フォント**でリデザイン済みです。

- **レイアウト**: 白/クリーム/濃紺を基調に、細い罫線（ヘアライン）で区切るセクション、左寄せの見出し、ダッシュ＋テキストの控えめなCTA（`.link-cta`）など、CBRE Japanの余白重視な構成を採用
- **カラー**: RE/MAX公式パレットを`css/style.css`の`:root`にCSS変数として厳密値で定義（Red `#FF1200` / Blue `#0043FF` / Cream `#F7F5EE` / Black / White / Dark Red `#650000` / Dark Blue `#000B35` / Bridge Red・Blue / Sky Blue / Dark Charcoal Gray）。背景は白・クリーム・黒中心、赤をCTA・アクセント、青を補助アクセントとして限定的に使用
- **フォント**: Google Fonts経由で Montserrat（Web推奨・ロゴ/見出し/数字）+ Zen Kaku Gothic New（日本語本文、Gothamに近い幾何学的な角ゴシック。Montserratは和文グリフを持たないため自動フォールバック）
- **コントラスト対応**: 赤地に白文字は基準（4.5:1）未達だったため検証のうえ、赤ボタンは黒文字（5.3:1）、ホバー時は濃赤地に白文字に切り替え

## 技術構成

- 素のHTML / CSS / JavaScript（ビルド不要）
- フォント: Google Fonts（Montserrat, Zen Kaku Gothic New）
- 画像: `images/` 配下のショッピングモール・マーケット写真（ヒーロー背景・取扱物件イメージギャラリー用、いずれもイメージ写真である旨を明記）


## 現在のセクション構成

商業不動産・店舗仲介向けに構成しています（住宅の売買・賃貸ではありません）。

1. ヘッダー（固定・6項目ナビ、1024px以下でハンバーガーメニュー）
2. ヒーロー（出店事業者・物件オーナーの両方に向けたメッセージ + RE/MAXネットワークのバッジ）
3. 共感・課題提起（商業不動産のよくある悩み3つとその回答）
4. 選ばれる理由（強み4項目、具体的事実つき）
5. 実績・ネットワーク数値（設立年、RE/MAX正式加盟時期、グローバル展開エリア、世界の拠点数）
6. サービス内容（出店事業者向け／物件オーナー・デベロッパー向けの2カラム）
7. 取扱物件タイプ（店舗・オフィス・倉庫）+ 取扱う商業施設のイメージギャラリー（※イメージ写真の注記あり）
8. サブCTAバナー（無料相談 + 物件情報受け取りフォーム、サービス内容直後）
9. ご相談の流れ（4ステップ、費用が発生しない旨を明示）
10. サブCTAバナー（流れ直後）
11. よくある質問（FAQ、アコーディオン6問）
12. サブCTAバナー（FAQ直後）
13. 会社概要（実在する会社情報のテーブル）
14. お問い合わせフォーム（リアルタイムバリデーション・送信中状態・信頼シグナル付き、フロントのみ・送信先未実装）
15. スマホ固定CTAバー（電話する / 無料相談する、スクロール50%超で表示、お問い合わせセクション表示中は非表示）

### 会社概要に掲載している情報の出典

公式サイト（[lomets-inc.com](https://lomets-inc.com/company/)、[remax-compass.jp](https://remax-compass.jp/)）から取得した情報を基に記載しています。掲載内容は取得時点のものなので、公開前に必ず最新情報と照合してください。

### 意図的に含めていない要素

- **お客様の声（テストモニアル）**: 実際の顧客の声が確認できなかったため、架空の証言を掲載していません。実際の声が集まり次第、セクションを追加してください。
- **具体的な物件情報（住所・賃料等）**: 実在の取扱物件データがないため、物件タイプ（店舗／オフィス／倉庫）の紹介のみに留め、具体的な物件カードは掲載していません。
- **会社の実写真**: オフィス外観等の実写真がないため、商業施設のイメージ写真を「※イメージです」の注記付きで使用しています。
