# SORA不動産 LP（不動産会社ランディングページ）

不動産会社向けのランディングページ。現時点ではダミーの会社情報・物件情報で構成されたテンプレートです。

## 技術構成

- 素のHTML / CSS / JavaScript（ビルド不要）
- フォント: Google Fonts（Noto Sans JP, Shippori Mincho）
- 画像: `images/` 配下のショッピングモール・マーケット写真（周辺環境セクション・ヒーロー背景用）＋物件/会社写真は picsum.photos のダミー画像（本番公開前に差し替え要）

## ファイル構成

```
index.html      … ページ本体（ヘッダー〜フッターまで全セクション）
css/style.css   … スタイル一式
js/main.js      … ヘッダーのスクロール演出・モバイルメニュー・フォーム送信の簡易処理
images/         … 周辺環境セクション・ヒーロー背景で使用するローカル画像
```

## 現在のセクション構成

1. ヘッダー（固定・スマホ用ハンバーガーメニューあり）
2. ヒーロー（キャッチコピー + CTA、背景に images/shopping-mall-3521181.jpg）
3. 選ばれる理由（強み4項目）
4. 実績数値（創業年数・成約件数など）
5. おすすめ物件（カード3件）
6. 周辺の生活環境（images/配下の5枚のギャラリー）
7. お客様の声（3件）
8. 会社概要（テーブル）
9. お問い合わせフォーム（フロントのみ・送信先未実装）
