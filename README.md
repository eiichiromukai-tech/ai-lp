# SORA不動産 LP（不動産会社ランディングページ）

不動産会社向けのランディングページ。現時点ではダミーの会社情報・物件情報で構成されたテンプレートです。

## 技術構成

- 素のHTML / CSS / JavaScript（ビルド不要）
- フォント: Google Fonts（Noto Sans JP, Shippori Mincho）
- 画像: `images/` 配下のショッピングモール・マーケット写真（周辺環境セクション・ヒーロー背景用）＋物件/会社写真は picsum.photos のダミー画像（本番公開前に差し替え要）

## ファイル構成

```
index.html      … ページ本体（ヘッダー〜フッターまで全セクション）
css/style.css   … スタイル一式
js/main.js      … ヘッダーのスクロール演出・モバイルメニュー・フォーム送信の簡易処理
images/         … 周辺環境セクション・ヒーロー背景で使用するローカル画像
```

## 現在のセクション構成

CV導線ブラッシュアップ（`lp-brushup-prompt.md` の指示）を反映し、以下の構成になっています。

1. ヘッダー（固定・7項目ナビ、1024px以下でハンバーガーメニュー）
2. ヒーロー（「相談は何度でも無料。しつこい営業はいたしません。」+ 実績バッジ）
3. 共感・課題提起（住まい探しでよくある不安3つとその回答）
4. 選ばれる理由（強み4項目、各項目に具体的事実を1行追加）
5. 実績数値（創業年数・成約件数など）
6. おすすめ物件（カード3件 + 周辺の生活環境ミニギャラリーを内包）
7. サブCTAバナー（無料相談 + 非公開物件リスト受け取りフォーム、ヒーロー直後）
8. ご相談の流れ（4ステップ、費用が発生しない旨を明示）
9. サブCTAバナー（流れ直後）
10. お客様の声（3件、検討条件と「不安→解決→結果」の3段構成）
11. よくある質問（FAQ、アコーディオン6問）
12. サブCTAバナー（FAQ直後）
13. 会社概要（テーブル）
14. お問い合わせフォーム（リアルタイムバリデーション・送信中状態・信頼シグナル付き、フロントのみ・送信先未実装）
15. スマホ固定CTAバー（電話する / 無料相談する、スクロール50%超で表示、お問い合わせセクション表示中は非表示）
