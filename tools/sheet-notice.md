# スプレッドシートに貼る注意事項

物件データのスプレッドシートに、**新しいタブを1枚追加して**、下の文面を
そのまま貼り付けてください。タブ名は「⚠️はじめにお読みください」など、
一番左に置いて最初に目に入るようにするのがおすすめです。

**物件データのタブには絶対に貼らないでください。**
1行目は見出し行として読み取っているため、注意書きの行を足すと取り込みが
止まります（サイトは古いまま残るので事故にはなりませんが、更新できません）。
タブを分けておけば、取り込み対象は `gid` で指定しているので影響はありません。

あわせて、物件データのタブの **A1セルにメモ**（右クリック →「メモを挿入」）で
下の【短縮版】を入れておくと、直接触る人の目にも留まります。

---

## 貼り付ける文面

```
■ このシートについて

このシートは、REMAX COMPASS 物件ポータル（Webサイト）の掲載内容そのものです。
ここに書いた内容が、そのまま一般のお客様が見るサイトに公開されます。

  詳しい手順（入力のしかた・写真の入れかた・エラーが出たときの対処）は
  運用マニュアルにまとまっています。初めての方は先にお読みください。
    → https://github.com/eiichiromukai-tech/ai-lp/blob/main/MANUAL.md


■ 【重要】書いてはいけないこと

このシートの中身は、実質的に「公開情報」とお考えください。
サイトの管理をGitHubという公開の場所で行っており、このシートのURLも
そこに記載されているため、社外の人でも見ようと思えば見られる状態です。

次のものは、絶対にこのシートに書かないでください。

  × 公開前・未公開の物件
  × オーナー様・貸主様・売主様の氏名や連絡先
  × 借主様・入居希望者様の氏名や連絡先
  × 社内メモ（値下げの余地、売却のご事情、他社との競合状況など）
  × 手数料の配分や、社内の利益に関する数字

未公開物件を管理したい場合は、このシートとは別に社内用のシートを作り、
公開が決まったものだけをこちらへ転記してください。


■ 編集するときのお願い

  ・1行目（見出し行）は書き換えないでください。列の追加・並べ替え・
    名前の変更もしないでください。取り込みが止まります。
  ・物件は1行につき1件です。行の途中に空行を入れても構いません。
  ・「物件番号」は物件ごとに固有の値にしてください。重複するとエラーになります。
  ・成約した物件は、行を消さずに「募集状況」を『成約済』にしてください。
    サイトの検索結果から自動で消えます。
  ・物件の内容を直したら、「情報更新日」も実際に直した日付にしてください。
    新着バッジと、取引条件の有効期限の判定に使っています。


■ サイトに反映されるタイミング

  ・毎朝8時（日本時間）に自動でチェックし、変更があれば反映します。
  ・急ぎのときは手動で反映できます。反映を担当する方にご連絡ください。
  ・入力に間違いがあった場合、サイトは一切書き換わりません。
    どの行の何が問題かが記録に残るので、直して再実行します。
    「間違えたら公開されてしまう」ということはないのでご安心ください。


■ 物件写真について

  写真はこのシートではなく、GitHubの images/properties/ に置きます。
  ファイル名は  物件番号-番号_キャプション.jpg  の形式です。
    例）CMP-1025-01_外観.jpg  CMP-1025-02_店内.jpg
  1物件につき10枚まで。番号の01がメイン画像になります。
  置きかたが分からない場合は、反映を担当する方にご連絡ください。


■ 広告表示のルール（宅建業法・不動産の表示に関する公正競争規約）

  このシートの内容はそのまま広告になります。次の点にご注意ください。

  【システムでは確認できません。人の目でお願いします】
  ・実際にはない物件、取引できない物件を載せない（おとり広告になります）
  ・「完璧」「日本一」「格安」「掘り出し物」「最高」などの断定的・最上級の
    表現は使わない（表示規約で禁止されています）
  ・「徒歩○分」は道路距離80mを1分として計算する（端数は切り上げ）

  【空欄だと警告が出ます。取り込みは止まりませんが、必ず埋めてください】
  ・賃貸物件の「契約期間」
  ・売買物件の「用途地域」
  ・土地（売買）の「私道負担」

  【空欄・書式違いだとエラーになり、取り込みが止まります】
  ・物件番号／物件名／物件種別／エリア（市区）／面積（坪）／情報更新日
  ・賃貸なら「月額賃料」、売買なら「販売価格」
  ・「築年月」の書式（例: 2015-04。年だけだと警告が出ます）
```

## 【短縮版】物件データタブのA1セルに入れるメモ

```
【重要】このシートの内容はそのままサイトに公開されます。
実質的に社外からも見える状態のため、未公開物件・オーナー様や
お客様の個人情報・社内メモは書かないでください。
1行目の見出しは書き換えないでください（取り込みが止まります）。
```
