# 一括登録するCSVの置き場所

Actionsの「物件をCSVから一括登録」で取り込むCSVを、ここに置きます。

GitHubの画面から **Add file → Upload files** でアップロードできます。

---

## ⚠️ 取り込みが終わったら、CSVを削除してください

**このリポジトリは公開されています。** ここに置いたCSVは、

- GitHubのページ
- サイトのURL（`https://property.lomets-inc.com/data/import/ファイル名.csv`）

の両方から、**誰でもそのまま読めます。**

物件の募集資料は、公開してよい範囲が決まっていることがあります。
仕入元からお預かりした資料をそのまま置いたままにしないよう、
**登録が済んだら、この場所から削除してください。**

削除のしかた: GitHubでファイルを開く → 右上の「…」→ Delete file

---

## 消しても大丈夫なのか

大丈夫です。取り込んだ内容は microCMS に入っており、
サイトの表示は microCMS から作られます。ここのCSVは**受け渡し用の控え**で、
残しておく必要はありません。

## 注意

一度コミットしたファイルは、削除しても **これまでの履歴には残ります。**
公開してはいけない資料をうっかり置いてしまった場合は、削除するだけでは足りません。
そのときはご相談ください（履歴からの削除が必要になります）。
